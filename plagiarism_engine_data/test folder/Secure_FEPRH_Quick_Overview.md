# Secure-FEPRH — Feature Overview (Quick Reference)

> **Previous students** built a basic code repository and English-only text similarity checker.
> **We are extending it** with Cybersecurity, Computer Vision, and Arabic NLP — adding **8 new features**.

---

## 🔄 Enhanced (From Previous Project)

| # | Feature | What's New |
|:--|:--------|:-----------|
| 1 | **Text Similarity Check** | Added **Arabic language support** (the majority of proposals are in Arabic) |
| 2 | **Code Repository** | Added encryption, file validation, malware blocking, and version history |

---

## 🆕 Completely New Features

| # | Feature | One-Line Description |
|:--|:--------|:---------------------|
| 3 | **Face Authentication (MFA)** | Login requires face scan via webcam + liveness check (anti-spoofing) |
| 4 | **Role-Based Access Control** | Students, Supervisors, and Department Head each have strict, enforced permissions |
| 5 | **Code Plagiarism Detection** | Detects copied code even when variable names are changed (structural analysis) |
| 6 | **Smart Attendance** | Camera auto-identifies attendees during discussion sessions — no paper sheets |
| 7 | **Kanban Task Board** | Trello-like board for supervisors to track student progress week by week |
| 8 | **Notifications & Alerts** | Auto-alerts for deadlines, feedback, and suspicious login attempts |
| 9 | **Analytics Dashboard** | Visual charts for the Department Head (project stats, similarity trends, workload) |
| 10 | **Security Hardening** | Rate limiting, encrypted sessions, input sanitization, and full audit logs |

---

**Total: 2 enhanced + 8 new = 10 features** covering Web Development, AI, and Cybersecurity.
