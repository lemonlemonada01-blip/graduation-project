# Secure-FEPRH: Ultimate Learning Resource Guide

This document contains the absolute best, hand-picked YouTube tutorials and crash courses for every single technology used in the Secure-FEPRH project. Share this with your team so everyone can master their specific module!

---

## 🚀 1. The Frontend Stack (React, Vite, Tailwind CSS)
*For the student handling UI, UX, and the frontend foundation.*

*   **[React JS Full Course 2023 | Build an App and Master React in 1 Hour](https://www.youtube.com/watch?v=bMknfKXIFA8)** *(JavaScript Mastery)*
    *   **Why:** The best modern crash course on React components, hooks (`useState`, `useEffect`), and props using Vite.
*   **[Tailwind CSS Full Course for Beginners](https://www.youtube.com/watch?v=lCxcTsOHrjo)** *(freeCodeCamp.org)*
    *   **Why:** A complete 3-hour deep dive into building beautiful, responsive UIs with Tailwind CSS, exactly like the ones used in our National Command Center dashboard.
*   **[Framer Motion Crash Course](https://www.youtube.com/watch?v=zVqczFZr124)** *(Net Ninja)*
    *   **Why:** Learn how to add the smooth micro-animations and page transitions we use in the layout.

## 🔒 3. Security & Advanced Backend (JWT, RBAC, Crypto)
*Also for the core architect.*

*   **[JWT Authentication in FastAPI](https://www.youtube.com/watch?v=s5vM_jJtCg8)** *(Indently)*
    *   **Why:** Explains how JSON Web Tokens work and how to implement Role-Based Access Control (RBAC) securely in FastAPI.
*   **[Python Cryptography Tutorial - Fernet & AES](https://www.youtube.com/watch?v=H8t4DJ3Tdrg)** *(NeuralNine)*
    *   **Why:** Essential for understanding how the Secure Repository encrypts and decrypts files before saving them to the disk.

## 🧠 4. Artificial Intelligence & Biometrics Engine
*For the student handling the Plagiarism and Attendance AI.*

*   **[Face Recognition with Python and OpenCV](https://www.youtube.com/watch?v=QSTnwsZj2yc)** *(Murtaza's Workshop)*
    *   **Why:** A brilliant, easy-to-follow guide on using the `face_recognition` library to encode faces into 128D arrays and compare them for attendance tracking.
*   **[Natural Language Processing (NLP) in Python - TF-IDF and Cosine Similarity](https://www.youtube.com/watch?v=hc2EMOEQFw8)** *(freeCodeCamp.org)*
    *   **Why:** Explains the exact math and code needed to compare project abstracts for text plagiarism.
*   **[Abstract Syntax Trees (AST) in Python](https://www.youtube.com/watch?v=yW63R7-5YJ0)** *(AnthonyWritesCode)*
    *   **Why:** Understand how to parse Python code into a tree structure to detect structural code plagiarism (bypassing variable renaming).
